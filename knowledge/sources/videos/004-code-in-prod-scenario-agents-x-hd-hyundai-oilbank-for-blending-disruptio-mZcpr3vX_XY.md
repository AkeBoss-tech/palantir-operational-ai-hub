## Official description

A refinery never stops. Now the ability to optimize it doesn't either.

At DevCon 6, Palantir Software Engineer Simon Kaufmann and Jinho Kim of HD Hyundai Oilbank launch Scenarios, a protected sandbox on the Ontology where agents can draft and stress-test without ever touching production data. Watch a scenario agent rebuild a full vessel and blending schedule after a shipping delay, validate every constraint in real time, and hand it off for a one-click merge into the live system.
