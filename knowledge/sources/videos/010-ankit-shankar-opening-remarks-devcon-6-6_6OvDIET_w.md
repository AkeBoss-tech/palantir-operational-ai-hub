# Ankit Shankar Opening Remarks | DevCon 6

**Official video:** [Watch on YouTube](https://www.youtube.com/watch?v=6_6OvDIET_w)
## Official description

"If we want to build meaningful agents that are doing real work, We need to be able to understand their work and build trust before increasing their autonomy."

At DevCon 6, Palantir Software Engineer Ankit Shankar unveils the Agent Stack, a set of products to help you build production agents for the enterprise, all built on the Ontology.
- Orchestrator for durable execution
- Agent Engine and Agent SDK for building agents of any shape
- Agent Manager for actionable telemetry and observability
- AIP Evolve for continuous, end-to-end optimization

Watch a simple agent get stress-tested against the real world — race conditions, human approvals, mid-task crashes — and see why trust, not intelligence, is what actually separates a good demo from a production agent.
